# VietHarmony App

## Introduction

VietHarmony App is a Python application created for the purpose of identifying traditional Vietnamese music genres.

## Installation

1. Clone the repository from GitHub:
   ```bash
   git clone https://github.com/thanhhuytran919/vietnamprime_app.git
   ```
2. Navigate to the project directory:
   ```bash
   cd vietnamprime_app
   ```
3. Install the dependencies from the `requirements.txt` file:
   ```bash
   pip install -r requirements.txt
   ```
4. Download Models
   [Models](https://drive.google.com/drive/folders/1qGGpQzRNya94Y9cGYCCdE7PDL7n5RJvn?usp=sharing).

## Requirements

To run the application, you need Python and pip installed on your computer. The necessary dependencies for the application will be installed automatically when running the installation command in step 3. Then, move models downloaded to App/model/... 

## Usage

1. Run the `app.py` file to start the application:
   ```bash
   python app.py
   ```
2. Upload an audio clip in WAV format no longer than 5 minutes and press the predict button.
3. The results will be returned and displayed below.
